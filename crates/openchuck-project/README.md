# openchuck-project

Project document model, text persistence, stable IDs and order keys, selection sets and content hashes.

Part of [OpenChuckCAM](../../README.md). Architecture section 5.6; requirements PRJ-01 to PRJ-08, TL-01 to TL-10, UI-05, VC-03.

**Status:** slice 1 in progress. The in-memory project document with stable IDs, model content hashes, selection sets and the cache folder for generated data are in place (decision record 0007). Saving and loading as TOML with per-item order keys (decision record 0006), schema versions and migration are next.
