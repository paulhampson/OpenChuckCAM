# openchuck-testkit

Test-only support (never a normal dependency; `cargo xtask deps` enforces this): the independent kinematic oracle and the independent gouge and coverage checker (architecture section 9; decision record 0018), the determinism harness (NFR-06), plain-text golden files (NFR-08), procedurally generated analytic test parts with the 1M-triangle benchmark model and the carving test piece (`CarvedRelief`, issue #382), and the independent oracle and corpus of 2D offsets on an unrolled cylinder (`region`).
