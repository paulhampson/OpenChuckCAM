# Lane ICON: icon concepts (throwaway branch, never merged)

Three original concepts, hand-written SVG (`gen_svgs.py` writes them), rendered with
Chromium through Playwright (`node render.js`) to `png/<concept>-{512,128,32,16}.png`
and `contact-sheet.png` (each concept on light and dark, 32 and 16 px also magnified).

- A `concept-a-jaws-a-axis`: chuck seen end-on (three jaws gripping round stock) inside an orange A-axis rotation arrow.
- B `concept-b-helix`: round stock held in a chuck, side view, with an orange helical toolpath wrapped round it.
- C `concept-c-tool-rotation`: side view of stock in a chuck, an end mill cutting from above and an orange A-axis rotation arrow round the stock.

Colours: tile #22344A with rim #4A6280, chuck #3E4F64, steel #AEBBC9, light #E8EEF4, accent #F59E1B.
