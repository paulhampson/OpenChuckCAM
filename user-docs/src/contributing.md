# Contributing to this guide

This guide is part of OpenChuckCAM's source, in the [`user-docs/`](https://github.com/paulhampson/OpenChuckCAM/tree/main/user-docs) folder of the repository, and it changes in the same pull request as the behaviour it describes. To report a mistake, open an [issue](https://github.com/paulhampson/OpenChuckCAM/issues) and name the page.

To change a page, read the guide's [style guide](https://github.com/paulhampson/OpenChuckCAM/blob/main/user-docs/STYLE.md) first, then the project's [contributing notes](https://github.com/paulhampson/OpenChuckCAM/blob/main/CONTRIBUTING.md). The documents that define the project itself, its requirements and design, are in [`docs/`](https://github.com/paulhampson/OpenChuckCAM/blob/main/docs/README.md); this guide is written from them for people using the program.
