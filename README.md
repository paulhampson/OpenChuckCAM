# CLA signatures

This branch holds the contributor licence agreement signatures recorded by CLA Assistant Lite (`.github/workflows/cla.yml` on `main`), in `signatures/cla.json`. Do not merge it into `main`, and do not protect it: the workflow writes here.

The agreements are [CLA.md](https://github.com/paulhampson/OpenChuckCAM/blob/main/CLA.md) (individuals) and [CLA-ENTITY.md](https://github.com/paulhampson/OpenChuckCAM/blob/main/CLA-ENTITY.md) (organisations; recorded by the maintainer).
