# Makera Z1 air-cut procedure (gate 4)

**Status: reviewed and accepted by the project owner, who operates the Z1 (14 Oct 2026), with no changes** (work breakdown slice 20 items 10 and 12; [decision 0031](decisions/0031-slice-20-packaging-and-trial-documents.md), OI-133, closed). Review is not a trial: nothing in this document has been run on a Z1 for generated programs. **Generated G-code is the user's to verify before running on a machine (NFR-12): read each program before you run it.**

This is gate 4 of [verification plan section 6](verification-plan.md), using the reference jobs in [reference-jobs.md](reference-jobs.md). It extends the SP-12 air cut ([decision 0007](decisions/0007-sp-12-z1-conventions.md); `spikes/sp12/AIR-CUT.md` on `spike/sp-12-z1-conventions`), which used a hand-written program, to programs generated by the application. Read the [safe-practice checklist](z1-safe-practice-checklist.md) first and complete its sections 1 and 2.

**Step-by-step instructions** for gates 4 and 5, with one-page checklists and results forms, are in [z1-gates-4-5-test-instructions.md](z1-gates-4-5-test-instructions.md) (lane GATES, draft for the owner's review). Step 3 was corrected on 22 Oct 2026 to time a whole operation (OI-910, the owner's answer), and step 0 records the owner's answers on the spindle and `T1 M6` (OI-911, OI-912).

**Rules (verification plan section 6).** Attended, emergency stop in reach, **no tool, no material**, reduced feed. Any unexpected motion stops the trial and is logged as a defect with the G-code attached.

## What gate 4 must show

1. The controller accepts every line of each program and raises no alarm.
2. The motion matches the simulator run (gate 3) and the A direction, wrap and unwind behave as decision 0007 recorded.
3. One simultaneous XYZA move takes the time the IR predicts for the Z1 feed rule, scaled for the reduced feed, within a band set at the first run (decision 0007: within about 10 % of the predicted time confirmed the rule in the SP-12 run).
4. The `G93` result on the installed firmware is recorded (SP-12 found it ignored on 1.1.2; the Z1 post never writes it).

## Before you start

- [ ] Checklist sections 1 and 2 are complete and signed.
- [ ] Firmware version noted: ________ (SP-12 was run on 1.1.2; a different version means the conventions in decision 0007 need rechecking, not assuming).
- [ ] **Axis height measured** (OI-60). The profile assumes the chuck centre is 45 mm above the bed with the bed at the bottom of the Z travel (-100), so the axis is at machine Z -55 and the safe Z is 50 mm above it. That reading is an assumption. Measured: ________ mm. If it differs, correct the machine profile, regenerate the programs and re-run `cargo test -p openchuck-app --test reference_jobs` (the golden files then change; review the diff). A wrong value moves every Z.
- [ ] Travel checked against the profile (200 x 200 x 100 mm, decision 0013, OI-39).
- [ ] Work zero set in G54 with **Y0 Z0 on the A axis centreline** and X0 at the part's model origin, with X0 at least 10 mm clear of the jaws (OI-40).
- [ ] **No tool in the spindle.** The generated programs contain `T1 M6` (OI-41): see step 0 for how to handle it. The tool change itself is not tested here.
- [ ] Chuck empty or with the jaws closed and nothing held; nothing loose on the bed; enclosure closed.
- [ ] A mark (tape) on one jaw to see the direction; a stopwatch.
- [ ] Application version and commit: ________ ; programs generated on: ________ ; checked against the golden files: yes / no.

## Steps

Run with **feed override at 10 %** unless the step says otherwise. Watch the first 20 lines of each program with a hand near the stop. Stop on anything unexpected.

## Pass and fail

- **Pass** (verification plan gate 4): motion matches the simulator; the controller accepts every command; no alarms; the measured time is within the band for the Z1 feed rule (agree the band at step 3, starting from the 10 % SP-12 result).
- **Fail:** any unexpected motion, alarm or rejected line. Stop, note the line, attach the program and the application commit to a defect, and do not go on to gate 5. A change to a post or to the kinematics sends the programs back to gate 1.

## After the air cut

Gate 5 (the first cut in wax or foam) follows only when gate 4 has passed and the checklist (sections 3 and 4) has been reviewed by the operator. Slice 20 item 11 also asks for a 3-axis test part first, to set the first-cut limit from the machine's own repeatability (start at ±0.1 mm), and the tool change test (OI-41).
