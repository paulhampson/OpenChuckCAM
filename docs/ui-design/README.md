# User interface design

This folder holds the design of the desktop application's interface.

| Document | What it settles |
| --- | --- |
| [ui-specification.md](ui-specification.md) | How the application looks and behaves: window layout, workflow steps, project tree, viewport, inspector, dock, footer, the screens of each step, supporting windows, per-user settings, visual tokens, wording, keyboard and accessibility, and how it differs from what is built |

**Status.** Proposed, with [decision 0038](../decisions/0038-ui-specification-and-requirements.md), which also proposes the requirements the design needs (UI-10 to UI-24, SIM-11 to SIM-13, GC-15, GC-16, NFR-15). Until the record is accepted the specification is guidance, not authority. Accepted decision records win over it.

**Design canvas.** The mockups are on a claude.ai design canvas, private to the project owner: <https://claude.ai/artifact/1Qi5cpiyAiz3r5DkFnXkbu>. The specification is the reviewed copy; the canvas is a working draft, like the other documents that began as artifacts (`docs/README.md`). When the two disagree, the specification wins and the canvas is updated.
